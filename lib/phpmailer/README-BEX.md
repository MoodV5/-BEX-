# Vendored PHPMailer

Version: **6.12.0**, upstream tag `v6.12.0`.

Source: https://github.com/PHPMailer/PHPMailer/tree/v6.12.0

The three unmodified SMTP core files in `src/`, upstream `LICENSE`, and package
metadata are included. No Composer installation is needed on the hosting server.
The 6.x line supports the existing PHP 7.4 environment; this does **not** make
PHP 7.4 supported or secure. Upgrade the server PHP version after checking the
existing applications, then review the current PHPMailer version before launch.
