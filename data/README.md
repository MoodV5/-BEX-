# 納入実績・取引先メーカー・スクリーン資料の管理

掲載方針の確認日：2026年10月18日。

納入実績・取引先メーカー・スクリーン詳細・図面資料は全て掲載し、スクリーンの製造・販売と「Visual Master」を引き継ぐ方針です。調査・対応履歴は [SITE-CONSISTENCY-NOTES.md](../SITE-CONSISTENCY-NOTES.md) と [PRODUCT-SPEC-AUDIT.md](../PRODUCT-SPEC-AUDIT.md) に記録しています。

## 編集する場所

- `reference-content.json`：納入先101件、設備説明136件、メーカー34件、スクリーン4シリーズ・44仕様。元ページ・資料のURLも記録しています。
- `../scripts/build-reference-pages.mjs`：ページ構成・説明文・表の表示方法。
- `../vm1.html`：スクリーン一覧と、生成ページの共通ヘッダー・フッター等の基準。
- `../reference.css`：実績・メーカー・図面ページのスタイル。
- `../downloads/visual-master/`：PDF44点、DXFのZIP44点。シリーズ別に保存しています。
- `../images/screens/`：旧サイトから引き継いだBE・BA・BS・BLの製品画像。

## ページの生成

プロジェクトのルートで次を実行します。Node.js標準機能のみを使い、追加パッケージは不要です。

```sh
node scripts/build-reference-pages.mjs
```

次の6ページを生成し、全HTMLの会社メニュー・フッターに導線を追加します。サイトマップも更新します。

- `concept_3.html`：納入実績
- `concept_4.html`：取引先メーカー
- `vm2.html`：BE ケース入り電動スクリーン
- `vm3.html`：BA 天板式電動スクリーン
- `vm4.html`：BS ケース入り手動スクリーン
- `vm5.html`：BL 天板式手動スクリーン

生成したHTMLを直接編集すると再生成時に置き換わります。更新はJSONデータか生成スクリプトに反映してください。生成済みの印がない同名のHTMLは、保護のため上書きしません。

## 情報の扱い

- 納入先名・メーカー名は元の掲載順・表記を引き継ぎ、名称が納入・取引当時のものを含む旨を表示しています。現在の社名への自動置換や、現在も取引中との一律の断定は行っていません。
- 納入当時の設備内容は実績として掲載し、販売終了した個別製品の現行商品としての紹介とは区別します。
- 図面は原本のまま保存しています。寸法・仕様の変更が必要な場合は承認された原本に差し替えてください。生成スクリプトは図面の内容を変更しません。
- ページ表示や資料ダウンロードにはビルドサーバーやPHPは不要です。HTML・CSS・画像・資料を公開サーバーへ配置して使います。
- 資料の入手元と公開先の対応はJSON内の `source` と `path` で追跡できます。旧資料URLの転送設定にも利用できます。
