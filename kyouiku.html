CALL・デジタルLL

Study & System

当社がご提案する教育システム

コンピューターを活用した教育が広く普及する一方、学習者の知識や操作スキルには幅があります。

パソコン教室にLLシステムを組み合わせたCALLシステムなら、一人ひとりの習熟度に応じた指導が可能です。

チエル株式会社

当社はチエル株式会社の販売パートナーとして、同社の授業支援ソフトを提供しています。
学習者一人ひとりにPCを用意し、映像・音声や教員が作成した資料を配信できます。授業時間外にもデジタル教材を用いて自学自習できるため、学習機会が広がります。

株式会社アンペール

当社は株式会社アンペールの販売パートナーとして、AdiLL（アディール）を提供しています。
「教科書と同じ手軽さで」をコンセプトに、従来のLL設備とデジタル技術の利点を組み合わせた語学授業支援システムです。学習者用端末は簡単に操作でき、教員用PC1台で運用できます。

視聴覚設備

Audio Visual Equipment

ディスプレイ、プロジェクター、スクリーンなどの映像機器と、マイクやスピーカーなどの音響機器を組み合わせ、使いやすさを重視したシステムを総合的にご提案します。

近年は、液晶プロジェクターにPC映像を投影し、ワイヤレスマイクを利用するケースが増えています。一方、PCとプロジェクターの組み合わせによっては、映像を正常に投影できない場合もあります。
当社は、導入後のトラブルを抑えるための知識と技術を生かして、安定したシステムを構築します。

現在は、アンプ、ミキサー、ワイヤレスマイクチューナーなどの機能を1台に集約した機器もあります。構成を簡素化しながら、液晶プロジェクターの制御にも対応できます。

高性能DSPを搭載。使いやすく多機能なデジタルミキサー

  • ✓ マイク４系統、ライン２系統のオーディオ入力を４系統に出力
  • ✓ ビデオ３系統、ＲＧＢ２系統のビデオ/ＲＧＢ入力
  • ✓ 切り替えスイッチで選択できる９種類のＡＶシステムをプリセット
  • ✓ ４ｃｈスピーカー出力のデジタルパワーアンプ内蔵
  • ✓ 別売チューナーユニット用装着スロットを２口装備
  • ✓ プロジェクター制御をはじめ、便利さを高める外部リモート端子
  • ✓ 赤外線リモコン受光部を前面パネルに装備
  • ✓ フロントガードパネル２枚を付属。１９インチラックマウントも可能
  • ✓ 付属のソフトウェアで詳細設定。基本設定はフロントパネルでも可能

遠隔講義システム

Remote Lecture System

ネットワークの高速化により、映像・音声を高品質に伝送できるようになりました。遠隔会議・講義システムも高精細化し、離れた拠点を結ぶ教育環境の整備が進んでいます。

離れたキャンパスをリアルタイムで結び、場所を問わず授業を実施できる環境を構築します。

  • ✓ 1080i ハイビジョン映像での通信を実現
  • ✓ デュアルストリームでHD映像とPC画面を30フレームで共有できる「データソリューション」機能を搭載
  • ✓ 通信中の映像にマーキング可能な「ビデオアノテーション」機能を搭載
  • ✓ HDカメラに新開発の「ブライトフェイス」機能を搭載
  • ✓ どこにでも持ち運びやすいコンパクトサイズ
