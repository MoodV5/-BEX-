# 株式会社ベックス Webサイト：最初に読むページ

このフォルダは、ベックスのWebサイトを作るための**編集用の原本**です。
ブラウザーに表示するファイルだけでなく、作業用の資料・自動チェックも含みます。
**フォルダ全体を公開サーバーへアップロードしないでください。**

## まず知っておくこと

- 通常のページはHTMLでできています。文章の修正にWordPressの管理画面は使いません。
- メニュー・フッターは共通部品を1か所直し、コマンドで全ページに反映します。
- 納入実績・メーカー・スクリーン詳細の6ページはデータから作ります。生成済みHTMLを直接直すと、次の生成で消えます。
- お問い合わせの送信だけはPHP対応サーバーが必要です。このPCでの見た目の確認と、実際のメール送信は別です。
- GitHubへの保存（push）と、本番サイトへの公開（アップロード）は別の作業です。

## 作業の基本

必要なものはコード編集用のエディターとNode.jsです。Node.js 24で動作確認しています。
このプロジェクトの基本コマンドは追加パッケージを使わないため、`npm install` は不要です。

VS Codeの場合、このフォルダを開き、「ターミナル → 新しいターミナル」を選びます。
ターミナルの場所がこのフォルダであることを確認します（`package.json` がある場所です）。

```powershell
node --version
npm --version
```

バージョン番号が出れば準備完了です。認識されなければ、Node.jsのセットアップを担当者に依頼してください。
PowerShellで `npm.ps1` がブロックされる場合は、実行ポリシーを変更せず `npm.cmd run check` のように `npm.cmd` を使えます。

1. 元に戻せるように、作業開始前のGitの状態を確認します。分からない変更は消さず、前任者へ確認してください。
2. [早見表](docs/MAINTENANCE.md)で編集する原本を選び、必要な内容だけを修正して保存します。
3. 次を順番に実行します。

```powershell
npm run generate
npm run check
npm run preview
```

`generate` は共通部品と生成ページを更新します。`check` は不整合を探します。`preview` は確認専用のサーバーを起動します。
表示された `http://127.0.0.1:8000/` をブラウザーで開きます。停止はターミナルで `Ctrl+C` です。
ブラウザーの自動再読み込みはしません。編集・保存・生成後に再読み込みしてください。プレビュー起動後に画像やページを追加した場合は、一度 `Ctrl+C` で止め、`npm run preview` を起動し直します。
`file:///...` でフォルダを開く方法では、トップページが一覧表示になるなど、本番と挙動が違います。

4. PCとスマートフォン相当の幅で、文章・画像・リンクを目視確認します。自動チェックの成功だけでは承認完了ではありません。
5. 掲載内容の承認後、[公開・復旧手順](docs/RELEASE.md)に進みます。上記コマンドでは本番公開もメール送信も行いません。

## 注意するファイル

- `dist/` は公開用のコピーです。**ここを編集せず、原本を直して作り直します。**
- `contact.php`・`.htaccess`・`lib/` は送信処理や安全対策です。意味が分からない状態で変更・削除しないでください。
- パスワード、管理画面のスクリーンショット、問い合わせの個人情報をGitやこの手順書に入れないでください。
- サーバー上の既存WordPressと、このHTMLサイトの管理方法は異なります。WordPressを勝手に削除したり、設定を上書きしたりしないでください。

## 本番の状況について

ローカルでの検査結果と、本番公開・サーバーでの適用状況は別です。
この資料だけで「公開済み」「メールが届く」「サーバー側の保護が有効」と判断せず、[引き継ぎ確認票](docs/HANDOVER.md)で実際の状況を確認してください。
